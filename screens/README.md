# App screenshots

Put two portrait screenshots from a phone here as `1.png` and `2.png`, then run:

```bash
scripts/make-phone-mockup.sh
```

That writes `site/images/app-screens.png`, the two-phone picture on the landing page. Commit that file (the screenshots in this folder are only the source).

Good choices: the map with a few features on it, and a second screen that shows something different (for example the main menu). Take them on a real device with realistic data, and avoid anything personal (callsigns, positions, server names you do not want public).
